# 鮨おまかせ図鑑 · Omakase Sushi Field Guide

一份可以同朋友分享嘅日本おまかせ壽司百科 — 108 種ネタ（魚、貝、蝦蟹、烏賊、海膽魚卵）、22 道料理、12 種技法、28 個壽司用語，連季節、味道、口感、食法同價位。

Single self-contained `index.html` — 冇任何 external dependency（除咗 Google Fonts），可以直接開、亦可以放上 GitHub Pages。

## 部署到 GitHub Pages

1. Create a new repo（例如 `omakase-guide`）
2. Upload `index.html`
3. Settings → Pages → Deploy from branch `main` / root
4. 拎到 `https://<username>.github.io/omakase-guide/` 就可以分享

或者用返 `https://<username>.github.io/<repo>/index.html` 直接開。
